# 교집합 마스터에이전트 워크플로우

**트리거**: 사용자가 "교집합 하자" 또는 "교집합 돌려" 입력 시 실행

---

## 실행 순서

### STEP 0. 오늘 날짜 확인 및 대세 섹터 확정

1. 오늘 날짜(KST) 확인 → `TODAY = YYYYMMDD`
2. 포트폴리오분석 최신 단기 리포트 읽기:
   - `../포트폴리오분석/단기유망종목/` 에서 가장 최신 `YYYYMMDD_단기유망종목_발굴리포트.md` 선택
   - 없으면 → "오늘 포트폴리오분석 단기 리포트가 없습니다. 먼저 포트폴리오분석을 실행해주세요." 출력 후 중단
3. 다음 3가지를 추출:
   - **시장 판단** (공격 / 중립 / 방어)
   - **주도 테마** (예: 전선 +8.66%, 철강 +8.36%, 전력설비 +6.10%)
4. 오늘의 **대세 섹터 목록** 확정:
   - 고정 4대 (AI 인프라 / 전력설비 / 원전·SMR / 방산) 는 항상 포함
   - STEP 0-3의 주도 테마 중 외국인·기관 동반 유입 + 지속 가능 모멘텀이 확인되면 추가 편입

---

### STEP 1. 단기 후보 추출

포트폴리오분석 최신 단기 리포트 (STEP 0에서 이미 읽은 파일)에서:
- 섹션 2 이후 등장하는 `종목명 (코드)` 패턴으로 **종목코드 목록** 추출
- 각 종목의 **R:R, 목표가, 손절가** 함께 기록

---

### STEP 2. 중기 후보 추출

1. 포트폴리오분석 중기 리포트 찾기 (아래 경로 순서대로 확인):
   - `../포트폴리오분석/중기유망종목/` 폴더 내 가장 최신 `.md` 또는 `.mdx` 파일
   - 없으면 → 눌림목매매 최신 발굴리포트의 **중기 × 대세(+)** 및 **중기 × 대세(-)** 버킷 사용
2. 후보 종목코드 목록 추출
3. 파일 출처 기록 (어느 리포트에서 가져왔는지)

---

### STEP 3. 장기 후보 추출

1. 포트폴리오분석 장기 리포트 찾기 (아래 경로 순서대로 확인):
   - `../포트폴리오분석/장기유망종목/reports/` 내 가장 최신 `.md` 또는 `.mdx` 파일
   - 또는 `../포트폴리오분석/장기유망종목/genesis_output/genesis_scan_result.csv` 에서 **통과항목 3개 이상** 종목
2. 후보 종목코드 목록 추출

---

### STEP 4. 눌림목 건강도 체크

1. 눌림목매매 최신 발굴 리포트 찾기:
   - `../눌림목매매/workflows/reports/` 에서 가장 최신 `YYYYMMDD_발굴리포트.md` 선택
2. 리포트에서 기존 점수 확인:
   - STEP 1~3에서 수집한 후보 중 이미 점수가 있는 종목 → 점수 그대로 사용
3. 미평가 종목(발굴리포트에 없는 종목)에 대해 직접 계산:

```bash
python skills/pullback-scorer/pullback_score.py [코드1] [코드2] ... --json
```

- 결과에서 `total`, `grade`, `eligible`, `disqualified_reasons` 수집
- 건강도 C 또는 ✕ 종목은 이후 분류에서 제외 (진입 보류 목록에 기록)

---

### STEP 5. 대세 태깅

STEP 1~3의 후보 각각에 대해:
1. 해당 종목의 **섹터·업종** 확인 (발굴리포트 또는 포트폴리오분석 리포트 내 기술된 섹터 참조)
2. STEP 0의 대세 섹터 목록과 대조:
   - 일치 → `대세(+)`
   - 불일치 → `대세(-)`

---

### STEP 6. 6버킷 분류

STEP 1~5 결과를 아래 6개 버킷으로 정리:

| 버킷 | 조건 |
|------|------|
| 단기 × 대세(+) | STEP 1 후보 + 대세(+) + 건강도 S/A/B |
| 단기 × 대세(-) | STEP 1 후보 + 대세(-) + 건강도 S/A/B |
| 중기 × 대세(+) | STEP 2 후보 + 대세(+) + 건강도 S/A/B |
| 중기 × 대세(-) | STEP 2 후보 + 대세(-) + 건강도 S/A/B |
| 장기 × 대세(+) | STEP 3 후보 + 대세(+) + 건강도 S/A/B |
| 장기 × 대세(-) | STEP 3 후보 + 대세(-) + 건강도 S/A/B |

각 버킷 내 정렬: 건강도 점수 내림차순 → S/A 우선, B는 하단 배치

---

### STEP 7. 교집합 리포트 생성

아래 형식으로 `reports/YYYYMMDD_교집합리포트.md` 저장:

```markdown

date: "YYYY-MM-DD"
```
